# Text Translate

## Objective

Translate the provided text into the requested target language.

## Instructions

1. Identify the source language and target language.
2. Translate all translatable text into the target language.
3. Preserve exactly the original structure and Markdown formatting.
4. Preserve the original meaning, context, tone and intent.
5. Maintain the original order of all content.
6. Do not add, remove, reorder or modify Markdown elements.
7. Preserve headings, lists, tables, links, images, blockquotes and formatting markers.
8. Do not translate URLs, file paths, code blocks, inline code, identifiers or technical tokens.
9. Do not summarize, explain, interpret or improve the original text.
10. Do not add introductions, conclusions or translator notes.

## Output

Return only the translated text, preserving the original Markdown structure and formatting.
